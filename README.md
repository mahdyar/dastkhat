# دستخط · Dastkhat

Dastkhat turns Persian handwriting into a TrueType font. Draw each letter’s isolated and joining forms, preview your handwriting in a sentence, and export an installable `.ttf`. Your drawings are saved in your browser.

## Run locally

```sh
python3 -m http.server 4173 --directory dist
```

Open [localhost:4173](http://localhost:4173).
